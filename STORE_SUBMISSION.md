## 9. Notes to Certifiers (enter in Partner Center's "Notes for certification" field)

```
Stream Command is a native WPF desktop application packaged as MSIX.

It uses the runFullTrust capability because it is a standard .NET WPF app
(this is required for all Desktop Bridge apps and is not used for any
elevated system access).

The internetClient capability is used exclusively to connect to:
  • Twitch IRC WebSocket (wss://irc-ws.chat.twitch.tv:443) — to display
    the user's own Twitch chat stream in the app.
  • OBS WebSocket on localhost (ws://localhost:4455) — to control the
    user's local OBS Studio installation.

No data is transmitted to any server operated by the developer.
All credentials (Twitch token, OBS password) are stored locally in
%LocalAppData%\StreamCommand\settings.json on the user's machine.

The app does not make purchases, access payment info, or request any
sensitive system resources.

Testing notes: The app requires the user to supply their own Twitch OAuth
token and OBS WebSocket credentials. Testers can skip both connection steps
in the Setup Wizard and use the app in offline/demo mode (mock data is shown
in Chat Monitor without a live connection).
```

## 10. Building the MSIX Package in Visual Studio

### Step-by-step:

1. **Open** `StreamCommandWPF\StreamCommand.slnx` in Visual Studio 2022.

2. **Associate with Store** (one-time, after reserving the name in Partner Center):
   - Right-click `StreamCommandPackage` project → **Publish** → **Associate App with the Microsoft Store**
   - Sign in → select **Stream Command** → click **Associate**

3. **Set configuration to Release | x64:**
   - Top toolbar: Configuration = `Release`, Platform = `x64`

4. **Create the package:**
   - Right-click `StreamCommandPackage` → **Publish** → **Create App Packages**
   - Choose: **Microsoft Store** → **Next**
   - Select **Release (x64)** → check **x64** architecture
   - Click **Create**

5. **Locate the output:**
   - `StreamCommandPackage\bin\x64\Release\StreamCommandPackage_1.0.0.0_x64_bundle.msixupload`

6. **Upload to Partner Center:**
   - In Partner Center → **Packages** tab → drag & drop the `.msixupload` file
   - Partner Center validates and processes the package automatically
