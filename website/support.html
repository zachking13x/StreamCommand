Support

Stuck on something, found a bug, or have an idea? Email zachking13@outlook.com and include your Windows version and what you were doing when it happened. Stream Command is made by one person, so replies can take a day or two.

The app also has a built-in Setup Guide in the sidebar that walks through connecting OBS and Twitch step by step.

Common questions

Stream Command says OBS is not connected

Make sure OBS Studio 28 or newer is open, then in OBS go to Tools, then WebSocket Server Settings, and tick Enable WebSocket server. Enter the same port and password in Stream Command's Settings. If OBS was started in Safe Mode, its WebSocket server is turned off, so restart OBS normally.

The keyboard shortcuts don't do anything

Another app may already be using the same key combination. Open Settings, Global shortcuts, and pick a different modifier (for example Ctrl+Alt instead of Ctrl+Shift). Shortcuts only control OBS while Stream Command is running and connected.

Go Live didn't start my stream

Going live or ending a stream from the keyboard needs two presses, so a stray key can never start a broadcast. Press the shortcut twice within a few seconds. Also check that OBS has a stream service and key set up in its own Settings.

The live preview is blank

The preview uses OBS Virtual Camera. In OBS, go to Tools and choose Start Virtual Camera (or use the Start Virtual Camera button in the Controls dock).

How do I disconnect my Twitch account?

Revoke Stream Command's access from your Twitch account under Settings, Connections. To also remove the saved sign-in from your PC, close the app and delete the %LocalAppData%\StreamCommand folder.

Where is my data kept?

Only on your PC, in %LocalAppData%\StreamCommand. See the privacy policy for the details.
